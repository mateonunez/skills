# Misc

Tools I keep around but rarely use.

- **[a11y-default-review](./a11y-default-review/SKILL.md)** — Quick accessibility pass after UI changes — keyboard nav, focus visibility, semantic HTML, aria-live, reduced motion. WCAG 2.1 AA bar.
- **[types-first-guards](./types-first-guards/SKILL.md)** — Use strict TypeScript patterns — discriminated unions for domain concepts, exhaustive checks, nominal typing where needed to prevent ID mix-ups at compile time.
- **[production-observability](./production-observability/SKILL.md)** — Include error telemetry, request context, and queue visibility in production code. Structured logging, tracing, metrics for external IO failures.
